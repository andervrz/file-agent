# File Agent

Gestión de archivos, terminal Linux y navegador web con lenguaje natural.

---

### Capacidades

| Tool | Qué puedo hacer |
|---|---|
| 📁 Archivos | Crear, leer, mover, copiar, eliminar, buscar |
| 📄 Documentos | Word, Excel, PowerPoint, PDF |
| 🌐 Navegador | Abrir URLs, buscar, hacer clic, leer páginas |
| 🔎 Búsqueda web | Información en tiempo real |
| ⚙️ Terminal | Comandos seguros con timeout |
| 🔀 Git | Status, add, commit, push, pull |
| 💾 Backup | Compresión zip/tar.gz |

### Sesiones

- **Sidebar izquierdo** — haz clic en cualquier conversación previa para continuarla
- **Nueva sesión** — usa el botón ➕ para empezar un chat fresco sin perder el historial
- Las sesiones se guardan automáticamente y persisten entre reinicios

### Comandos rápidos

Usa los botones de la barra de acciones o escríbelos directamente:

- **➕ Nueva sesión** — inicia una conversación nueva
- **🗑️ Limpiar** — limpia el historial de contexto del agente
- **📊 Traces** — muestra los últimos 5 turnos con métricas
- **🧠 Memoria** — lista los hechos guardados en sesión
- **📈 Stats** — tokens, tools ejecutados y errores de la sesión

### Tips

- Los archivos creados aparecen como adjuntos descargables en la respuesta
- Las capturas del navegador se muestran inline en el chat
- Cada tool call aparece como un paso colapsable con input y output
- Al cambiar de sesión en el sidebar, el agente recupera el contexto completo
